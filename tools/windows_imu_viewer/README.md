# IMU viewer — тестовое приложение для Windows

Подключается к инерционному модулю STM32F303 (MPU6050 + QMC5883L) по
COM-порту (USART2, 115200, бинарный протокол с CRC16-CCITT —
[docs/PROTOCOL.md](../../docs/PROTOCOL.md)) и показывает:

- **компас** — азимут (0° = север, по часовой стрелке) с цифровым значением;
- **искусственный горизонт** — крен и тангаж;
- **кватернион** — столбиковая диаграмма w/x/y/z (корпус → ENU);
- **числовые значения** — углы, гироскоп (рад/с), акселерометр (м/с²),
  магнитное поле (мкТл), температура, частота потока, статус датчиков,
  версия прошивки и аптайм;
- **команды** — пинг, «ноль азимута», сброс смещения, калибровка гиро и
  магнитометра (старт / стоп+сохранение), сохранение во flash, запросы
  инфо и калибровки.

## Запуск

Требования: Windows 10/11, Python 3.9+ (tkinter входит в стандартный
инсталлятор python.org, галочка `Add Python to PATH`).

Вариант 1 — двойной клик по `run.bat` (при первом запуске сам
установит `pyserial`).

Вариант 2 — вручную:

```bat
pip install pyserial
python imu_viewer.py
```

### Режим симуляции (без платы)

Чтобы посмотреть, как выглядит и ведёт себя приложение, без железа:

```bat
python imu_viewer.py --sim
```

Порт не нужен, pyserial не нужен: приложение само генерирует кадры
50 Гц — медленное вращение по азимуту (20°/с), плавные качания крена
и тангажа, гравитация 9.81 м/с², «все датчики OK». Кнопки команд тоже
работают (симулятор отвечает ACK). Запустите «Подключиться» — приборы
оживут.

## Сборка в один EXE

PyInstaller не кросс-компилирует (из Linux), поэтому EXE собирается
на самой Windows — одним кликом:

```bat
make_exe.bat
```

Скрипт сам ставит `pyserial` и `pyinstaller` (если нет) и собирает
`dist\imu_viewer.exe` (~15–25 МБ). Запуск:

- с платой: `dist\imu_viewer.exe` (выбрать COM-порт, 115200);
- симуляция: `dist\imu_viewer.exe --sim`.

Если скрипт говорит «Python НЕ найден» (или появляется сообщение
«Python was not found; run without arguments to install from the
Microsoft Store») — в системе нет настоящего интерпретатора, а `python`
в PATH — это алиас Windows Store. Установите Python 3.9+ с
python.org, отметив при установке «Add Python to PATH», и запустите
`make_exe.bat` снова (бат ищет также лаунчер `py` и типовые каталоги
установки).

Замечания:

- Консольное окно рядом с GUI — намеренно: в нём видны ошибки
  (порт занят, нет pyserial и т.п.). Для сборки без консоли добавьте
  флаг `--windowed` в команду PyInstaller в `make_exe.bat`.
- Антивирусы иногда ложно срабатывают на EXE из PyInstaller;
  если SmartScreen предупредит — «Подробнее → Выполнить в любом случае».
- Исходный EXE в Git не коммитится — пересобирается командой выше.

## Подключение

1. Плата через USB-UART адаптер (3,3 В): TX адаптера → RX платы,
   RX адаптера → TX платы, GND–GND (см. [docs/WIRING.md](../../docs/WIRING.md)).
2. В приложении: выбрать COM-порт (кнопка «↻» перечисляет порты),
   скорость 115200, «Подключиться».
3. Через 1–2 с (после автокалибровки гиро) начинаются кадры:
   компас и горизонт оживают, внизу — скорость потока (норма 50 кадров/с).

## Команды

| Кнопка | Что делает |
|---|---|
| Пинг | Проверка связи (ожидается `ACK Пинг: OK`) |
| Ноль азимута | Текущее направление становится 0° (смещение запоминается) |
| Сброс смещения | Убирает смещение азимута |
| Калибровка гиро | ~2 с, плата должна лежать неподвижно |
| Калибровка маг: старт | Начало калибровки компаса: вращайте плату во всех плоскостях (в т.ч. «восьмёркой» / «снежинкой») ~30 с |
| Калибровка маг: сохранить | Останавливает и сохраняет параметры во flash |
| Сохранить во flash | Сохраняет текущие калибровки/настройки |
| Запрос инфо | Версия прошивки, аптайм, статусы, склонение |
| Запрос калибровки | Текущие параметры калибровки (hard/iron, дрейф гиро) |

Полное описание процедуры — [docs/CALIBRATION.md](../../docs/CALIBRATION.md).

## Если ничего не работает

| Симптом | Причина / решение |
|---|---|
| Порта нет в списке | Драйвер USB-UART адаптера (CH340 / CP210x / FTDI); диспетчер устройств |
| «Порт занят» / ошибка подключения | Закройте Serial Monitor CubeIDE, PuTTY и т.п. |
| Порт есть, кадров нет | Скорость должна быть 115200; TX/RX крест-накрест; GND общий; уровни 3,3 В |
| Кадры идут, но азимут «плавает» | Не сделана калибровка магнитометра или рядом металл/магниты |
| `ACK …: ошибка железа` | MPU6050/QMC5883L не отвечает по I2C — проверьте питание и SDA/SCL |
