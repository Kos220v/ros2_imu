# Подключение

## Питание и шины

MPU6050 и QMC5883L — оба на I2C1 (400 кГц):

| STM32F303 | MPU6050 (GY-521) | QMC5883L (GY-271) | Примечание |
|---|---|---|---|
| PA15 (I2C1_SCL) | SCL | SCL | подтяжки 4.7 кОм к 3.3 В (обычно уже на модулях) |
| PB7 (I2C1_SDA) | SDA | SDA | |
| 3.3V | VCC | VCC | |
| GND | GND | GND | |
| GND | AD0 | — | адрес MPU 0x68 |

Адреса: MPU6050 `0x68`, QMC5883L `0x0D`. Если AD0 притянут к VCC —
поменяйте `IMU_MPU6050_ADDR7` на `0x69` в `imu_config.h`.

## UART к роботу (ROS 2)

USART2, 115200 8N1, бинарный протокол:

| STM32F303 | Робот / USB-UART |
|---|---|
| PA2 (USART2_TX) | RX |
| PA3 (USART2_RX) | TX |
| GND | GND |

Уровни 3.3 В! Для Raspberry Pi подключайте напрямую к GPIO UART
(TX↔RX крест-накрест). Для ПК используйте USB-UART адаптер 3.3 В.

Важно: скорость USART2 (115200) задана в `MX_USART2_UART_Init()` вне
USER CODE-секций. При перегенерации кода из CubeMX (.ioc) выставьте
115200 в настройках USART2 вручную, иначе вернётся старое значение.

## Отладочная консоль

USART1, 9600 8N1, текст:

| STM32F303 | USB-UART |
|---|---|
| PC4 (USART1_TX) | RX |
| PC5 (USART1_RX) | TX |
| GND | GND |

При старте плата печатает версии, статусы датчиков и источник калибровки.

## Монтаж

- Ось X платы — вперёд по ходу робота, Y — влево, Z — вверх.
- Если плата стоит иначе — задайте перестановку в `imu_config.h`
  (`IMU_MOUNT_*`) вместо переворачивания в ROS.
- Магнитометр боится железа и токов: держите моторы, динамики,
  силовые провода минимум в 10–15 см; калибруйте маг на собранном роботе.
- MPU6050 и QMC5883L должны быть жёстко закреплены относительно друг друга.
